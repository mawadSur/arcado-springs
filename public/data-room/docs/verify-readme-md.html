verify/ — what this folder is

verify/ is where the Cottages at Arcado Springs R-1 → R-2 rezoning package keeps its evidence: the raw, unedited output of the generator scripts in tools/ (so that any number printed in docs/ can be traced back to the calculation and the primary source it came from), the scripts that test the documents against data/layout.json and against the house rules of FACTS.md §6, and the two working records that get filled in as the application moves — the pre-application conference answers and the legal-notice evidence that RZ-2025-01 did not have when it was tabled on 2025-08-28 for a defective advertisement and sign. None of it is submitted to the City of Lilburn; the filed package is docs/ and drawings/. Read a file here when you want to know where a number came from or whether a document still agrees with the data, and file into it whenever a date, an answer or a piece of paper arrives that the package will later need to prove.

adjoiners-output.md Raw output of tools/adjoiners.py — every parcel sharing a boundary with the assemblage, grouped by side (northeasterly / King David Manor, northwesterly / Nantucket, southwesterly / Legends at Parkview), with PIN, property address, owner(s) of record and mailing address exactly as the Gwinnett County Tax Assessor 2026 Property Ownership file carries them, the run of common boundary in site-local u/v feet, and the digest acreage. 31 privately owned parcels, all zoned R-1 (City of Lilburn), plus the Gwinnett County Arcado Road right-of-way = 32 notice recipients. docs/06-adjoining-property-owners.md (Application Instructions item 10) is written from this; verify/notice/ checks the City's mailing list against it. check_dev_summary.py The checker for docs/02-development-summary.md only. It tests the house rules of FACTS.md §6 (the disclaimer block and the <!-- architecture-studio:requires-disclaimer --> marker as the last line; the package's standing prohibition on the certainty verb — every finding must read "appears consistent with"; no pre-2024 IFC edition), the presence of all ten sections and of every required row of the zoning matrix, and about thirty numbers against data/layout.json and data/dev-summary-derived.json. Run it with cd status/cottage-submission-2026-08-28 && python3 verify/check_dev_summary.py. It currently reports FAIL on six values (open space 32.2 %, impervious 38.4 % and 160,167 SF, open space 134,382 SF, lane 1,722 ft, hammerhead spacing 727 / 550 / 435) because docs/02 still carries layout-v1 prose while data/layout.json carries v2 — the failure is real and is the same finding as audit-2026-09-03/docs-consistency.md §2.2. The broader checker for all eleven documents is tools/check_docs.py.
